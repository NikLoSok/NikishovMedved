# Пироги Винни-Пуха — Уровень 3 🐻🥧

Учебный проект по веб-программированию: динамическая браузерная мини-игра на чистом HTML, CSS и JavaScript с плавной параболической анимацией и системой частиц.

## Демо

🔗 **Публичная ссылка:** https://github.com/NikLoSok/NikishovMedved

## Особенности игры

- **Автоматическая подача пирогов:** каждые 700 мс в верхней части экрана появляются пироги (🥧) в случайных координатах.
- **Физика полёта по дуге:** пироги летят к Винни-Пуху по параболической траектории с вращением на 720° и плавным замедлением (easing).
- **Система частиц:** при попадании пирога в цель разлетаются брызги мёда (🍯) с использованием CSS-переменных и `@keyframes`.
- **Игровой таймер и счётчик:** сессия длится ровно 20 секунд, ведётся подсчёт съеденных пирогов в реальном времени.
- **Адаптивность под экран:** координаты появления и траектория расчёта подстраиваются под размеры окна браузера.

## Технологии

- **HTML5** — разметка игрового поля и элементов интерфейса.
- **CSS3** — градиентный фон, абсолютное позиционирование, анимация частиц `@keyframes` с динамическими переменными (`--dx`, `--dy`).
- **JavaScript (ES6+)** — игровая логика, работа с DOM, математика траекторий (`Math.hypot`, тригонометрия), `requestAnimationFrame` для плавной 60 FPS анимации, `setInterval` и `setTimeout`.

## Как запустить локально

1. Скачайте репозиторий (**Code → Download ZIP**) или склонируйте его через терминал:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в папку проекта:
   ```bash
   cd winnie-pies
   ```
3. Откройте файл `index.html` двойным кликом в любом современном браузере — игра не требует сборки, сервера или установки зависимостей.
